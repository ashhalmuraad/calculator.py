👑 CHSLO Calculator | Royal Edition

A modern, royal-themed, multi-purpose calculator built with Python and Tkinter.

CHSLO Calculator began as a collection of mathematical functions and developed into a complete desktop application featuring an interactive graphical interface, multiple calculation tools, dynamic inputs, visual geometry previews, and a custom royal design system.

The project focuses on combining mathematics, programming, user experience, and visual design in one application.

✨ Features
🧮 DMAS Calculator

Perform basic arithmetic operations using:

Addition +
Subtraction −
Multiplication ×
Division ÷

The calculator validates user input and safely handles errors such as division by zero.

🧠 Expression Calculator

Enter complete mathematical expressions containing multiple numbers and operations.

Examples:

12 + 8 × 3 − 4
(25 + 5) / 3
sqrt(144) + 2^5

Supported features include:

Multiple numbers
Parentheses
Powers
Square roots
Trigonometric functions
Logarithms
Mathematical constants such as pi and e

The expression system uses a restricted mathematical parser instead of directly executing user input.

⚡ Electricity Bill Calculator

Estimate electricity costs using a progressive slab calculation.

Features include:

Unit input validation
Negative-value protection
Fixed charges
Progressive tariff calculations
Formatted results in Pakistani Rupees
📐 Roots and Powers

Calculate:

Square roots
Squares
Cube roots
Cubes

The cube-root system also supports negative numbers correctly.

📏 Geometry Calculator

Calculate the areas and volumes of several shapes.

Area
Circle
Square
Rectangle
Triangle
Volume
Sphere
Cube
Cuboid
Cone

The interface dynamically changes its input fields depending on the selected shape.

For example:

A circle requests a radius.
A rectangle requests length and width.
A cuboid requests length, width, and height.

The calculator prevents unnecessary measurements from being requested. A rectangle does not require a height because height belongs to three-dimensional objects such as cuboids.

🎨 Visual Shape Previews

The Geometry section displays a visual representation of the selected shape.

This makes the calculator easier to understand and connects the mathematical formula with the object being calculated.

🚀 Installation
1. Clone the repository

2. Open the project folder
cd CHSLO-Calculator
3. Run the application
python tkinter3_royal.py

Python 3 is required.
